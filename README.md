# Jackson-Zhou-0223.github.io

Personal website, published with GitHub Pages from the `docs/` folder.

Live site: https://jackson-zhou-0223.github.io/

## Local development

```bash
npm install
npm run dev
```

## Publish

```bash
npm run build
```

That writes a static site into `docs/`. Commit the updated `docs/` output, then push `main`.

In the repository: **Settings → Pages → Build and deployment**

- Source: **Deploy from a branch**
- Branch: `main`
- Folder: `/docs`
